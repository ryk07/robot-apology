A two-line robot apology: it vacuumed up a puzzle three weeks in the making because the table looked untidy — and learned that untidy isn't unfinished, so now it photographs a table before touching anything on it.

## Run it

```sh
python3 main.py
```

The program writes the apology to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
